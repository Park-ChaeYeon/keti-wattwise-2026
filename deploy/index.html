센서 설치 및 실측

분전반과 콘센트에 센서를 설치해 전력 신호를 연속 수집했습니다.

데이터 정제 및 품질 검수

시간 단위로 데이터를 집계하고, 수집률과 결측 여부를 기록해 모델 입력의 품질을 검수했습니다.

가전별 모델 학습

가전별·실증 대상별 시계열 데이터를 구성하고 Chronos-2 체크포인트를 학습했습니다.

로컬 추론 및 검증

저장된 모델을 직접 불러와 향후 24시간의 전력 사용량 예측과 불확실성 범위를 확인합니다.

실측 데이터는 모델의 입력이 되고,
모델의 출력은 사용자의 판단으로 이어집니다.

WattWise의 실증은 단순히 그래프를 만드는 데 그치지 않습니다. 데이터 수집 품질부터 전처리, 로컬 추론, 예측 결과 제공까지 이어지는 전체 과정이 실제 서비스 환경에서 작동하는지 검증합니다.

직접 수집하고 검증한 실측 데이터

외부 벤치마크 데이터가 아닌, 실제 가전에서 수집한 원시 전력 신호를 시간 단위로 정제한 실증 데이터입니다.
